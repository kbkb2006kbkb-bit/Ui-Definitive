# Design Document — Modern Main Menu for Anomaly

## 1. Визуальная концепция

### Название стиля
**Modern Zone**

### Настроение
Тёмный, атмосферный, современный, чистый.  
Ощущение "высокотехнологичного терминала в Зоне" + кинематографичность.

### Цветовая палитра

| Элемент              | Цвет                  | Hex       | Описание                      |
|----------------------|-----------------------|-----------|-------------------------------|
| Фон                  | Почти чёрный + туман  | #0A0F14   | Тёмный кинематографичный      |
| Акцент (hover/active)| Radiation Teal        | #2EE6A6   | Главный акцент                |
| Текст обычный        | Холодный белый        | #E8F0F2   | Читаемость                    |
| Текст вторичный      | Приглушённый серый    | #8BA0A8   | Версия, disclaimer            |
| Панель кнопок        | Полупрозрачный тёмный | #0D1218CC | Боковая/центральная панель    |
| Слайдер              | Акцентный + glow      | #2EE6A6   | Выделение текущего пункта     |

- Без тяжёлых рамок

## 2. Элементы

### Фон
- Высококачественный атмосферный арт Зоны (1920×1080 или 2560×1440)
- Лёгкий виньетинг + subtle grain
- Можно 2–3 варианта (день/ночь/аномалия)

### Логотип
- Чистый современный логотип Anomaly / "THE ZONE"
- Полупрозрачный, без тяжёлых теней

### Шниага (слайдер)
- Тонкая горизонтальная/вертикальная полоска с glow
- При наведении — мягкое свечение акцентного цвета

### Кнопки
- Без тяжёлых 3D-рамок
- Текст + тонкая линия слева/снизу при hover
- Плавный переход цвета

### Музыка
- Тёмный ambient / industrial / post-apocalyptic
- Рекомендуемые направления: dark ambient, atmospheric drone, лёгкий industrial
- Файл: `sounds/music/modern_menu_theme.ogg`

## 3. Технические решения

### Файлы
- Основной: `gamedata/configs/ui/ui_mm_main_16.xml`

### Совместимость с MCM
Во всех секциях меню **обязательно** присутствует:
```xml
<btn name="btn_mcm" caption="ui_mm_menu_mcm" />
```

### Шрифты
- Основной: `letterica18` + увеличенный `btn_height`
