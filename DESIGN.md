# KillTrack Unique Main Menu — Design Document

## Концепция: **Terminal Zone**

Полностью другая компоновка, чтобы не быть похожим на существующие минималистичные моды.

### Что отличает от скриншота и похожих модов

| Обычные моды (как на скрине)      | Наш мод (Terminal Zone)                  |
|-----------------------------------|------------------------------------------|
| Кнопки справа                     | Кнопки **слева**                         |
| Маленький шрифт letterica18       | Крупный **graffiti32**                   |
| Почти чёрный пустой фон           | Полноэкранный кинематографичный фон      |
| Тонкая полоска-слайдер            | Акцентная линия + левый градиент         |
| Стандартный правый shniaga        | Левый "терминальный" layout              |

### Цвета

- Акцент: `#2EE6A6` (radiation teal)
- Текст кнопок: холодный белый `#DCE6EB`
- Левый градиент: почти чёрный с прозрачностью
- Тонкая вертикальная линия-разделитель
