# Необходимые ассеты для Modern Main Menu

## 1. Текстуры (DDS)

Положи файлы в `gamedata/textures/ui/`

| Файл                    | Размер (рекомендуемый) | Описание                                      |
|-------------------------|------------------------|-----------------------------------------------|
| `ui_mm_modern_bg.dds`   | 1920×1080 или 2560×1440 | Основной атмосферный фон Зоны                |
| `ui_mm_modern_panel.dds`| 344×768 (или больше)   | Полупрозрачная тёмная панель справа          |
| `ui_mm_modern_logo.dds` | 512×256 / 1024×512     | Современный логотип                          |
| `ui_mm_modern_slider.dds`| 560×96                | Слайдер (акцентный цвет + glow)              |

### Рекомендации по стилю текстур

**Фон (`ui_mm_modern_bg`):**
- Тёмный, кинематографичный
- Туман, радиация, руины, аномалии
- Лёгкий виньетинг по краям
- Без слишком ярких элементов в правой части (там кнопки)

**Панель (`ui_mm_modern_panel`):**
- Почти чёрная с прозрачностью ~60–70%
- Можно добавить тонкие вертикальные линии / noise

**Слайдер (`ui_mm_modern_slider`):**
- Горизонтальная полоска
- Основной цвет: radiation teal (#2EE6A6)
- Мягкое свечение по краям

**Логотип:**
- Чистый, современный
- Можно "THE ZONE" / "ANOMALY" / кастомный

## 2. Музыка

Положи в `gamedata/sounds/music/`

| Файл                      | Формат | Описание                          |
|---------------------------|--------|-----------------------------------|
| `modern_menu_theme.ogg`   | OGG    | Атмосферный dark ambient / drone  |

Рекомендуемая длина: 2–5 минут, seamless loop.

## 3. Временные fallback'и

Пока нет своих текстур, можно временно использовать ванильные пути в XML.
