# Kill Confirm + Killstreak (Contract Wars style)

Чистый скриптовый аддон для **S.T.A.L.K.E.R. Anomaly** + **xray-monolith 2026.10.11 MT**.  
Без изменений движка.

## Возможности

- Стильное подтверждение убийства (текст по центру снизу)
- **Killstreak** с отдельными текстами и звуками
- Разные сообщения:
  - обычный **KILL**
  - **HEADSHOT**
  - **KNIFE KILL**
  - **GRENADE KILL**
  - **LONG RANGE**
  - **MUTANT DOWN**
- Killstreak:
  - 2 — DOUBLE KILL
  - 3 — TRIPLE KILL
  - 4 — QUAD KILL
  - 5 — PROKILL
  - 7 — RAMPAGE
  - 10 — LEGENDARY
  - 15 — UNSTOPPABLE
  - 20 — GODLIKE
- Показ дистанции и текущего стрика
- Звуки полностью из папки аддона
- Стрик сбрасывается при смерти игрока или после 8 секунд без убийств

## Установка

1. Скопируй папку `gamedata` из этого архива в корень игры (или в мод через MO2).
2. Положи свои звуки `.ogg` в:
   ```
   gamedata/sounds/kill_confirm/
   ```
3. Запусти игру. В логе должно появиться:
   ```
   [kill_confirm] loaded | killstreak + confirm ready
   ```

## Список звуков (создай эти файлы)

| Файл                    | Когда играет          |
|-------------------------|-----------------------|
| `kill.ogg`              | Обычный килл          |
| `headshot.ogg`          | Хедшот                |
| `knife.ogg`             | Нож / холодное оружие |
| `grenade.ogg`           | Граната               |
| `long_range.ogg`        | Дальний выстрел       |
| `mutant.ogg`            | Убийство мутанта      |
| `double_kill.ogg`       | 2 килла подряд        |
| `triple_kill.ogg`       | 3                     |
| `quad_kill.ogg`         | 4                     |
| `prokill.ogg`           | 5+                    |
| `rampage.ogg`           | 7+                    |
| `legendary.ogg`         | 10+ / 15 / 20         |

Если какого-то файла нет — звук просто не проиграется (игра не упадёт).

## Настройка

Открой `gamedata/scripts/kill_confirm.script` и в начале файла найди таблицу `CFG`:

```lua
local CFG = {
    streak_timeout    = 8000,   -- мс без убийств → сброс стрика
    long_range_dist   = 45.0,   -- метров
    point_blank_dist  = 3.5,
    ui_show_time      = 2200,   -- сколько висит текст
    sound_volume      = 0.85,
    ...
}
```

Тексты и цвета стриков можно менять в таблице `STREAK_TEXTS` и `SPECIAL_TEXTS`.

## Совместимость

- Работает с обычными и MT-сборками monolith
- Не конфликтует с большинством модов (использует стандартные callback’и)
- Можно ставить вместе с APM / другими killfeed’ами (будет показывать свою плашку)

## Известные ограничения

- Определение хедшота приблизительное (по кости последнего попадания)
- Некоторые экзотические мутанты/НПС могут не ловиться (редко)
- Для красивой иконки оружия можно позже добавить текстуры в `textures/ui/kill_confirm/`
